# Examples

This directory is provided for storing sample input and output images.

## Suggested Usage

Place your test earring images (`.jpg`, `.png`) and optional abstract background
templates here. The pipeline expects input as a `.zip` archive of earring photographs.

## Sample Workflow

1. Place raw earring photos in this directory.
2. Compress them into a `.zip` file.
3. Upload the `.zip` through the Gradio web interface.
4. The pipeline will generate three output variations per earring.

## Output Types

| Output | Description |
|--------|-------------|
| White Studio | Clean product shot on neutral white canvas with drop shadow |
| Abstract Background | Composited onto a brand background with color harmonization |
| On-Model Mockup | AI-generated photorealistic fashion model wearing the earring |
